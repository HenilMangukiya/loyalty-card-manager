# Loyalty Card Manager

A Flutter application for managing loyalty cards with features like:
- Card management (add, edit, delete)
- Barcode/QR code scanning
- Card expiration notifications
- Profile management
- Dark/Light theme support

## Features

- 📱 Modern and responsive UI
- 🌓 Dark/Light theme support
- 🔍 Card search functionality
- 📸 Image support for card logos
- 📊 Card statistics
- 🔔 Expiration notifications
- 👤 User profile management

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio / VS Code
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/loyalty-card-manager.git
```

2. Navigate to the project directory:
```bash
cd loyalty-card-manager
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```
